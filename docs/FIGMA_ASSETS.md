# Figma assets — exported with the project

В новой сборке используются настоящие исходные материалы, полученные из приложенного Figma ZIP (PDF export):

- `public/artwork/{slug}.webp` — восемь оригинальных художественных иллюстраций. Каждый фон из PDF извлечён отдельным JPEG-объектом и перекодирован в WebP без использования готового скриншота страницы.
- `public/decor/ornament-{top,bottom}-{left,right}.svg` — четыре угловых золотых орнамента. Контуры восстановлены из оригинальной книги/орнамента, встроенного как исходное изображение в PDF; в SVG нет букв, текстов или QR-кодов.
- `public/brand/monogram.svg`, `public/brand/wordmark.svg` — исходные эмблема и логотип, восстановлены в SVG; альтернативный текст/ссылки добавляются компонентом Brand.
- `public/decor/grunge.webp` — тёмная бумажная текстура.
- `public/legacy/home/` — старые оригинальные ассеты для главной: фото группы, альбомы, соцсети, видео-ссылка.

Все строки песен, названия и подписи остаются настоящим HTML. Значки музыкальных платформ строятся как inline SVG в `MusicIcon.tsx`.

Оригинальный файл шрифта `Columbina AltCap` не предоставлен. Добавлять/распространять его без лицензии нельзя. При получении лицензированного WOFF2 можно подключить в CSS или через `next/font/local`; fallback уже настроен.
