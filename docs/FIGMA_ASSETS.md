# Figma: оригинальные иллюстрации и орнаменты

**Актуальный источник:** https://www.figma.com/design/F8leIFIeOd92JrfLwtS647/

В Figma доступны 8 песен (desktop 1440px, mobile 360px), короткие/развёрнутые варианты, мобильное меню и две версии новой шапки с `BE/RU/EN`. Программная структура и тексты песен разобраны.

**Ограничение архива:** исходные фоновые изображения и декоративные файлы не удалось загрузить в рабочее окружение — ссылки Figma API на временные файлы недоступны при сборке здесь. Не используем скриншот целого фрейма как фон или замену HTML. Поэтому до импорта фоновые сцены и декоративные рамки отображаются с аккуратным CSS fallback. Настоящее pixel-perfect соответствие можно подтвердить только после импорта оригинальных assets и лицензированного шрифта Columbina AltCap.

## Автоматический экспорт через REST API

На своём Mac, имея права на файл и персональный Figma API token с правом чтения файла:

```bash
export FIGMA_TOKEN='ВАШ_ТОКЕН_ЛОКАЛЬНО'
npm run assets:figma
unset FIGMA_TOKEN
npm run build
```

Скрипт `scripts/import-figma-assets.mjs` обращается к новой копии файла `F8leIFIeOd92JrfLwtS647`; ищет только индивидуальные слои `фон` в 16 desktop/mobile макетах и сохраняет оригинальные image fills (или рендер конкретного слоя, когда нет raw image fill). Дополнительно выгружает точные узлы логотипов и орнамента через Figma API, не целые страницы. Итоговые файлы в `public/artwork/`, пути обновляются в `src/data/artwork.generated.json`.

Если Figma API ограничивает количество запросов или нет прав доступа, экспортируй слой `фон` для каждой страницы, логотипы и декор вручную, без UI и текста, и заполни `artwork.generated.json`:

```json
{
  "_common": {
    "headerLogo": "/artwork/header-logo.png",
    "footerLogo": "/artwork/footer-logo.png",
    "corners": { "topLeft": "/artwork/corners-top-left.svg" }
  },
  "intro": { "desktop": "/artwork/intro-desktop.webp", "mobile": "/artwork/intro-mobile.webp" }
}
```

Обязательно проверь, что файлы существуют по указанным путям. До production оптимизируй крупные фоновые изображения по разрешению и формату. Не вкладывай персональный Figma token в Git.

## Типографика

- `Inter` — основной UI и тексты. Используется через Google Fonts CSS, локальный fallback.
- `Philosopher` — навигация и запасной декоративный шрифт. Совпадает с новой шапкой Figma. Доступен через Google Fonts CSS.
- `Columbina AltCap` — **настоящий display-шрифт** заголовков песен в Figma, в архиве **нет** бинарного файла и нет разрешения на его распространение. Получи webfont/лицензию у автора дизайна и подключи локально самостоятельно; не загружай чужие шрифты в открытый репозиторий без лицензии.

Тестовые белорусские символы: `І і Ў ў`, также русские `Ё ё`, латиница. До релиза проверь наличие глифов у лицензированного display-шрифта; не допускай автоматического смешения fallback внутри слова.

## Предпубликационная проверка

- Сопоставить кроп фоновых иллюстраций для 1440px и 360px и посмотреть на промежуточных размерах 768px/1024px.
- Проверить SVG-рамку и золотые элементы в открытом и закрытом состоянии текста песни.
- Проверить 8 × 3 локали и 10 корневых QR URL на GitHub Pages.
- Проверить подтверждённость email (в Figma написано `gmal.com`), социальных ссылок и будущих музыкальных платформ.
