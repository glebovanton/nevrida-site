# QA checklist — перед публикацией

1. `nvm use && npm install && npm run check:content && npm run build`.
2. `npm run start`, открыть `http://localhost:3000` — **старая главная** с группой, альбомами, соцсетями, видео.
3. Проверить `/intro/`, `/zabiary-miane/`, `/taverna-dlya-syabrou/`, `/kalyhanka/`, `/tsyabe-mala/`, `/vouchaya-krou/`, `/zhahi/`, `/ty-geta-ya/`.
4. Проверить `/ru/intro/`, `/en/intro/`, `/ru/`, `/en/` и язык в HTML + canonical/hreflang.
5. Кнопка текста песни открывает/закрывает полные стихи без JS, фрейм расширяется, футер опускается.
6. Проверить mobile 360/390/430 px и desktop 768/1024/1440/1920 px: нет горизонтального overflow; золотая рамка не перекрывает буквы.
7. Бургер, смена языков, клавиатурная навигация и видимый focus работают.
8. Ссылки из QR-кодов точно соответствуют старым адресам.
9. `nevrida1`/`nevrida2` имеют `noindex` до готовности, rider пока без утверждённого отдельного URL.
10. Корректные SEO теги в сгенерированном `out/` и валидный `sitemap.xml`.
11. Проверить почту `nevridaland@gmal.com` у владельца перед публикацией.
12. Если требуется pixel-perfect, добавить лицензированный Columbina AltCap и визуально сравнить с оригинальной Figma в Chrome/Safari.

В этом архиве не приведены результаты автоматизированного сравнения браузерных скриншотов: они недоступны в данном рабочем окружении. Программно проверены наличие и формат ресурсов, CSS, TS/TSX, контроль маршрутов.
