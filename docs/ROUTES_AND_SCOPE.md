## Языки и SEO

Белорусский код — `be` (ISO 639-1); `by` — код страны.

- `https://nevrida.by/intro/` — белорусская версия по умолчанию, без `/be/`.
- `https://nevrida.by/ru/intro/` — русская версия.
- `https://nevrida.by/en/intro/` — английская версия.
- Каждая версия имеет свой `<html lang>`, canonical и взаимные `hreflang` `be`, `ru`, `en`, `x-default`.
- В sitemap включены **только** готовые восьмерки песенных страниц по трём языкам; главная и незавершённые служебные страницы исключены из sitemap и помечены `noindex`.
- Автоматический редирект по языку браузера сознательно НЕ используется: GitHub Pages — статический хостинг, QR URL должны оставаться стабильными.

## CSS и performance

Используются `rem`, `clamp()`, Grid, Flexbox и ограничение максимальной ширины. CSS не масштабирует целую desktop-картинку. Inter используется для обычного текста, Philosopher для навигации и запасного декоративного набора; полный шрифт заголовков Columbina AltCap нужно передать и лицензировать отдельно. HTML статический (SSG), раскрытие текста и мобильного меню выполнены на `<details>` без клиентского React-state.
